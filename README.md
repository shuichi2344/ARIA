# ARIA — Agentic Retail Intelligence & Analytics

AI-powered customer behavior simulation platform for Malaysian SMEs. ARIA creates realistic virtual customers using LLMs and real demographic data, letting business owners test "what-if" scenarios before making real decisions.

---

## Project Structure

```
ARIA/
├── aria/                   # Python backend package
│   ├── agents/             # LLM-powered agents (profiler, scenario suggestion)
│   ├── api/                # FastAPI application + security middleware

│   ├── database/           # Supabase REST client
│   ├── external/           # External APIs (DOSM, News, Malaysia Calendar)
│   ├── llm/                # LLM clients (Ilmu AI + Ollama fallback)
```

## Quick Start

### Prerequisites

- Python 3.12+
- Node.js 18+
- Ollama (for local LLM fallback): https://ollama.ai
- Supabase project (for database): https://supabase.com

### 1. Clone and configure

```bash
git clone <repo-url>
cd ARIA
cp .env.example .env
# Fill in your actual values in .env
```

### 2. Backend setup

```bash
pip install -r requirements.txt
ollama pull qwen2.5:7b          # Download the fallback LLM model
python start_api.py             # Starts FastAPI on http://localhost:8000
```

### 3. Frontend setup

```bash
cd frontend
npm install
npm run dev                     # Starts Next.js on http://localhost:3000
```

### 4. Open the app

Navigate to http://localhost:3000. Register an account, complete onboarding, and start simulating.

## How It Works

1. **Onboarding** — Business owner provides their business info (name, type, location). An LLM agent infers the customer profile (target demographics, price sensitivity, customer type).

2. **Ask a question** — User types a business question like "What happens if I raise prices by 10%?" or "A new competitor opened nearby."

3. **Scenario generation** — The system generates 2-5 simulatable scenarios using the LLM, optionally enriched with real-time news and economic data from Malaysia.

4. **Population synthesis** — Agents are created using Iterative Proportional Fitting (IPF) with real DOSM census data for the business's district, ensuring statistically valid demographics.

5. **LLM personality generation** — Each agent gets a unique personality profile generated by the LLM, grounded in their demographics and the business context.

6. **Simulation** — Agents make visit/skip/churn decisions using the LLM as their "brain." A two-phase process runs: independent decisions first, then peer influence where connected agents can change each other's minds.

7. **Report** — Results are aggregated into a risk assessment with revenue estimates, breakdown by customer segment, and actionable recommendations.

## Key Features

- **🎯 Monte Carlo CV Stopping (INTEGRATED ✅)** — **NEW:** Dynamic simulation stopping based on Weighted Composite Index convergence. Automatically runs 5-30 iterations until statistical convergence (CV ≤ 5%). **Saves 30-50% on LLM API costs** while ensuring statistically rigorous results. Enabled by default for all simulations. See `MONTE_CARLO_INTEGRATION_COMPLETE.md` for details.
- **Dual LLM provider** — Ilmu AI (Malaysian sovereign cloud) as primary, Ollama (local) as fallback. Automatic failover.
- **Real demographic data** — IPF engine uses DOSM census data for Penang districts to create statistically valid agent populations.
- **B2C, B2B, and Hybrid** — Supports consumer businesses, B2B suppliers, and mixed models with configurable split ratios.
- **Peer influence network** — Agents are connected in income-weighted social networks and can influence each other's decisions.
- **Real-time streaming** — Simulation progress streamed to the frontend via Server-Sent Events (SSE), including Monte Carlo convergence metrics.
- **Agent personality caching** — Reuses generated personalities within the same chat session for consistency.
- **Simulation settings** — Configurable demographics (income levels, age groups), target segments, agent count, and Monte Carlo parameters.
- **PDF reports** — Downloadable simulation reports with risk assessment, Monte Carlo convergence data, confidence intervals, and cost savings.
- **External context** — Optional integration with News API and Malaysia public holiday calendar for context-aware scenarios.
- **Security hardened** — Rate limiting, input validation, secure headers, no client-side secrets.

## Tech Stack

### Backend
- Python 3.12, FastAPI, Pydantic
- Ilmu AI (OpenAI-compatible) + Ollama (local LLM)

- Supabase (PostgreSQL via REST API)

- jsPDF (report generation)

- DOSM (Department of Statistics Malaysia) — demographics

## Environment Variables
